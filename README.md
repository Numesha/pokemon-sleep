# ポケスリ 食材厳選ロードマップ v3

欲しい食材と食材構成から候補ポケモンを探し、厳選先の島を比較する非公式ファンツールです。

- 食材・6パターンの複数選択、厳選状況・名前・島・睡眠タイプによる検索
- 島ごとの進化前優先、ポケモン単位の除外・復元
- 最優先・将来・仮採用のポケモン種類数による島の比較と睡眠タイプ別内訳
- ブラウザー保存、JSONバックアップ、旧版の食材厳選状況の引き継ぎ
- スマホ向けレイアウト、Excelから公開用データを作る更新画面

ビルドやインストールは不要です。`index.html` と同じ階層に他の同梱ファイルを置いてください。

詳しい使い方・GitHubへのアップロード・今後のデータ更新・補正内容は、[使い方と更新手順](使い方と更新手順.txt)を参照してください。

通常利用時に外部サービスへの通信はありません。Excel・バックアップはブラウザー内で読み取ります。

Excel読み取りには同梱のJSZipを使用します。[ライセンス](JSZip-LICENSE.txt)。
